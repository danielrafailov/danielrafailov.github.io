# Daniel Rafailov — Portfolio

A minimal, single-page personal site built with React, TypeScript and Vite.

## Develop

```sh
npm install
npm run dev
```

## Edit content

All text lives in [`src/data.ts`](src/data.ts): profile, experience, projects and education.
Styles are in [`src/index.css`](src/index.css), and colors are defined as variables at the top, with a dark-mode set below them.

## Deploy

Pushes to `main` deploy on Vercel.
